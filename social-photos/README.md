# Social photo scrape — provenance record

Captured via `.github/workflows/fetch-social-photos.yml` from The Ice Hut's
public Facebook page (facebook.com/morinvilleicehut). Google Maps and Bing
image search yielded nothing usable (map required sign-in; image search
returned unrelated businesses).

Only one genuinely usable, on-brand photo turned up: `p1.jpg`, the shop's
own Facebook profile picture (5 pastel sorbet scoops in cones). It's been
resized/optimized and copied to `images/real-fb-cones.jpg` for use on the
site. See `manifest.tsv` for the original source URL and metadata.
